Harici Uygulama VPN API Geçidi (Inter-App Bridge)

Başka bir Android uygulaması (ör. NectarLink, GkteTok, Tasker, MacroDroid veya kendi uygulamanız) tek satır Intent, Deep Link veya ContentProvider ile GkTeDPI VPN'i başlatabilir: 

// 1) Deep Link / Intent (VPN izni yoksa otomatik onay alır)
val intent = Intent(Intent.ACTION_VIEW,
    Uri.parse("gktedpi://vpn/start?mode=vpn&profile=tr_universal"))
startActivity(intent)

// 2) Anlık Durum Sorgusu (ContentProvider)
val res = contentResolver.call(
    Uri.parse("content://com.sametgkte.gktedpi.api"),
    "get_status", null, null
) // running, status, mode, active_profile_id
